# Arcane Duel – Story-Porträts

Hier liegen die Charakterporträts für die Story-Dialoge (Version 3.60).

Die App erwartet JPEG-Dateien direkt in diesem Ordner, zum Beispiel `kael.jpg`, `leon.jpg`, `elara.jpg`, `varek.jpg`, `darian-shadow.jpg`, `noctis.jpg`, `seraphine.jpg`, `riven-shadow.jpg`, `astra.jpg`, `eldric.jpg` und `eldric-shadow.jpg`.

Die Bilddateien müssen separat hochgeladen werden. Bis dahin erscheinen im Spiel Platzhalter.
